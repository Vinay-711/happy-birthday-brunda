# Birthday Tribute for Brunda

A personal static birthday website built with HTML and local image assets. The entry point is [index.html](index.html); this is a creative frontend project rather than a backend service.

## Preview locally

```sh
python3 -m http.server 8080
```

Open http://localhost:8080. No Node.js installation, package manager or build step is required for the checked-in page.

## Customize and check

Edit the text in `index.html` and keep asset paths relative so the page can be hosted under a repository subpath. Check the layout at phone and desktop widths, image loading, keyboard interaction, and audio behavior where present. A static page cannot persist a shared guestbook without an external service.

Use only photos, messages and audio you have permission to share. Review personal content before publishing the page. There is no automated test suite or release pipeline claimed by this README.
